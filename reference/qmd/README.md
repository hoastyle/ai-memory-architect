# QMD 记忆系统参考方案

**版本**: 2.0
**类型**: 远程 GPU 加速的语义搜索系统
**状态**: 参考方案

---

## 方案概述

QMD (Quantum Memory Dynamics) 是一个基于远程 GPU 服务器的记忆搜索增强系统，提供三种搜索模式：BM25 全文搜索、语义搜索和混合搜索。

### 核心特点

- **远程 GPU 加速**：使用 RTX 5080 GPU 进行语义搜索
- **三种搜索模式**：BM25、语义、混合（智能路由）
- **文件同步机制**：rsync 自动同步本地文件到远程服务器
- **智能降级**：搜索失败时自动降级到更简单的模式

---

## 架构对比

### QMD 架构
```
本地环境 → rsync 同步 → 远程 GPU 服务器 → 搜索结果
```

### supersystem 架构（个人版方案）
```
本地环境 → SQLite + 规则引擎 → 本地处理 → 记忆整合
```

---

## 适用场景

### ✅ QMD 适合
- 已有 GPU 服务器资源
- 需要强大语义搜索能力
- 跨大量文档的搜索需求
- 可接受网络依赖

### ❌ QMD 不适合
- 个人用户（硬件成本高）
- 本地化部署需求
- 低硬件要求场景
- 数据隐私敏感场景

---

## 与个人版方案对比

| 维度 | QMD | supersystem |
|------|-----|-------------|
| 部署 | 远程服务器 + 复杂配置 | 本地一键安装 |
| 硬件 | RTX 5080 GPU（必需） | 2核CPU + 2GB内存 |
| 网络 | 必须连接远程服务器 | 完全本地化 |
| 能力 | 搜索工具 | 完整记忆系统 |
| 成本 | 数千到数万元 | 接近零 |

---

## 结论

QMD 是优秀的语义搜索增强工具，但不适合作为个人版记忆方案的核心。其远程部署、GPU 依赖、网络要求等特点，使其更适合企业场景作为可选的搜索增强模块。

**个人版推荐**：supersystem（当前方案）
**企业版可选**：QMD 作为 WeKnora 的搜索增强模块
